# 优化“关于我们”页面 (About Us Page Optimization)

## 1. 修复导航栏遮挡问题 (Fix Navigation Bar Overlap)
- **问题分析**：用户反馈“黑色定位条挡住导航栏”，这通常是因为二级导航栏 (`.snavbar`) 误用了 `position: fixed` 或 `absolute` 且层级过高，或者顶部内边距设置不当。
- **解决方案**：在 `custom.css` 中显式定义 `.snavbar` 的样式，将其设置为 `position: relative` 或 `sticky`（位于 Header 下方），并确保其背景色和布局符合设计规范。
- **预期效果**：黑色二级导航条位于白色主导航栏下方，互不遮挡，且随页面滚动正常显示。

## 2. 优化顶部 Banner 图片 (Optimize Top Banner)
- **问题分析**：顶部图片 (`.mbnr img`) 被反馈“太大且显示不全”，目前可能默认为自然高度，导致占据过多屏幕空间且比例失调。
- **解决方案**：
  - 限制 `.mbnr` 容器的高度（例如 `480px` 或 `500px`）。
  - 对图片应用 `width: 100%; height: 100%; object-fit: cover;`，确保图片在限制高度内完整填充，同时保持良好比例。
  - 添加圆角和阴影处理，使其与整体“大气”风格保持一致。

## 3. 内容区域排版与动效优化 (Layout & Animation Optimization)
- **目标区域**：公司介绍 (`.p-about-profile`)、企业文化 (`.p-about-scale`)、荣誉资质/环保等级 (`.p-berneck-cert`)。
- **实施细节**：
  - **容器卡片化**：为各板块添加白色背景、圆角 (`border-radius: 24px`)、柔和阴影 (`box-shadow`) 和合适的内边距 (`padding: 60px`)，使其像首页产品矩阵一样精致。
  - **排版优化**：
    - **公司介绍**：优化文字 (`.cnc`) 的行高、字体大小和段落间距，提升阅读体验。
    - **企业文化**：限制图片最大宽度，添加圆角和悬停效果。
    - **荣誉资质**：美化 Swiper 轮播容器，调整证书图片的展示尺寸和间距。
  - **动效植入**：为每个板块添加 `fadeIn` 或 `slideUp` 进入动画，增加页面活力。

## 执行计划
1.  编辑 `theme/2020/static/css/custom.css`，添加针对 `.snavbar`、`.mbnr` 及各内容板块的专用样式。
2.  保存并刷新预览，验证导航栏遮挡问题是否解决，Banner 显示是否正常，以及内容排版是否美观。
