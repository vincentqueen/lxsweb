# CONSENSUS - 后台登录与页面优化共识

## 1. 明确的需求描述
- **后台登录**：确认账号为 `admin` 或 `kefu`。提供密码重置方案（重置为 `123456`）。
- **页面统一**：将 `classid=2,4,5,41,47,28,6` 统一为 `about.php` 风格。
- **图片优化**：Banner 比例 21:9，列表图 `object-fit: contain` 防止拉伸。

## 2. 技术实现方案
- **密码重置**：创建一个临时的 `reset_pwd.php` 脚本，调用 SDCMS 的数据库类 `sdcms_db` 来更新 `sd_admin` 表。
- **SQL 修复**：针对 `classid=28` 报错，检查 `cate.php` 或相关模板中的 SQL 语句，确保字段名正确。
- **样式复用**：在 `custom.css` 中定义 `.p-berneck` 统一类，并在各模板中引用。

## 3. 验收标准
- 使用 `admin` 或 `kefu` 配合新密码能成功登录后台。
- `classid=2,4,5,41,47,28,6` 页面不再出现重叠，图片显示完整。
- `classid=28` 页面不再报错。

## 4. 任务边界
