## 项目与任务特性规范
- 项目：SDCMS 模板站点，主题目录为 theme/2020
- 技术栈：PHP 模板 + 前端静态资源（custom.css）
- 变更范围：仅首页（hero 与两个 section）与页脚（footer）样式与排版
- 风格约束：保持白+绿色调，增强科技质感与高级感

## 原始需求
1. `div` 文字直接居中
2. 两个 `section` 版块“太小气”，参考给定设计
3. `footer` 太乱太长，优化排版
4. 增加 hero 进入动画

## 边界确认（范围）
- 不改动后端逻辑与数据结构
- 不新增第三方依赖
- 不改移动端模板（仅桌面主题 2020）
- 不改变已有内容文案，仅调整排版与交互表现

## 需求理解（对现有项目的理解）
- 首页结构：theme/2020/index.php 中的 hero + section + footer
- 样式集中在 theme/2020/static/css/custom.css
- 页脚模板在 theme/2020/include/foot.php

## 歧义与决策
- “参考页面设计”：按参考页的“更大留白、更高密度展示、更强对齐感”方向处理
- “div 文字居中”：指 hero 文案区域整体文字居中
- “footer 太乱太长”：通过列数收敛、信息聚合、表单紧凑化降低视觉长度

## 已做决策
- hero 文案区改为居中对齐，按钮组居中
- 两个 section 提升间距、卡片尺寸与网格密度
- footer 改为更紧凑的三列布局 + 精简信息块
- hero 增加 CSS 入场动画（图片与文案分层进入）
