## 明确需求与验收标准
### 需求
1. Hero 文案区域文字居中，按钮组居中
2. “核心产品矩阵/品质承诺”两区块更大气：卡片更大、留白更舒展
3. Footer 信息更有秩序：更短、更清晰的版式
4. Hero 增加进入动画（不花哨）

### 验收标准
- Hero 文案区域在视觉上居中对齐
- 两个 section 视觉密度提升且间距更舒适
- Footer 列结构清晰，阅读负担下降
- Hero 在页面加载时有平滑入场动画

## 技术实现方案
- 样式集中在 theme/2020/static/css/custom.css
- Footer 结构调整在 theme/2020/include/foot.php
- 仅使用 CSS 动画与布局，不引入新库
