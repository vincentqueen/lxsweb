# ALIGNMENT_页面统一优化

## 项目上下文分析
- **项目结构**：SDCMS 2.0 驱动的 PHP 网站。
- **技术栈**：PHP, SQLite (sdcms.db), SDCMS 模板引擎, CSS3 (Grid/Flexbox).
- **现有代码模式**：使用 `{$variable}` 进行变量输出，`{sdcms:rs}` 进行数据查询，`include` 引入公共组件。
- **业务域**：企业官网，展示产品系列、公司简介、新闻中心等。

## 需求理解确认
- **原始需求**：
  1. 将 classid=2,4,5,41,47,28,6 页面统一按照 classid=1 (about.php) 的结构进行优化。
  2. 修复排版重叠问题。
  3. 确保图片展示完整性（Banner 比例 21:9，文化图比例 2.5:1）。
  4. 解决后台登录密码错误问题。
- **边界确认**：
  - 仅针对指定的 classid 进行模板统一。
  - 仅修复 CSS 布局和模板结构，不涉及后端逻辑重构。
- **需求理解**：
  - 需要修改 `custom.css` 以支持统一的布局样式。
  - 需要更新各 classid 对应的 PHP 模板文件，确保使用相同的 body class 和 banner 结构。
  - 需要重置管理员密码以恢复后台访问。

## 智能决策策略
- **歧义点**：
  - classid=28 (新闻中心) 是列表页，其结构与关于我们（单页）略有不同，决定保持列表功能但套用关于我们的视觉风格（Banner、容器宽度等）。
- **技术决策**：
  - 使用 `object-fit: contain` 确保 Banner 图片在 21:9 容器内完整显示。
  - 使用 `md5` 加密重置管理员密码。
